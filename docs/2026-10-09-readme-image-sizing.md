# 프로필 이미지 표시 크기 통일

사용자 요청에 따라 Members Clinic처럼 다른 프로젝트 사진도 README 본문 너비에 맞춰 확대했다.

- 620px 또는 720px으로 고정된 프로젝트 화면·사진·리포트·수상 이미지는 width="100%"로 통일한다.
- 개미 투자자 키우기의 세로 화면 두 장은 기존 나란한 배치를 유지하면서 각각 width="48%"로 표시한다. 고정 높이 480px은 제거해 원본 비율에 따라 확대한다.
- 배지, 이미지 원본·주소, 설명, 접이식 상세 구조와 다른 README 내용은 유지한다.
- diff에서 표시 크기 속성만 바뀌었는지 확인하고 GitHub 프로필의 이미지 표시 너비를 검증한다.
