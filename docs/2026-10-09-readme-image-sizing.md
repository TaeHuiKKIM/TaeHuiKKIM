# 프로필 이미지 표시 크기 통일

본문 전체 너비로 확대한 뒤 사용자 피드백에 따라 화질과 가독성의 균형을 위해 표시 크기를 한 단계 줄였다.

- 가로 프로젝트 화면·리포트는 width="680"을 유지한다. GitHub의 기본 max-width: 100%에 따라 좁은 화면에서는 본문 너비로 축소된다.
- 최종 사용자 피드백에 따라 세로 이미지 네 장(DeepRacer 수상 사진, 개미 게임 두 화면, 카카오테크캠퍼스 수상 사진)만 height="440"으로 표시한다. 원본 비율과 가운데 정렬, 게임 화면의 나란한 배치를 유지한다.
- 배지, 이미지 원본·주소, 설명, 접이식 상세 구조와 다른 README 내용은 유지한다.
- diff에서 표시 크기 속성만 바뀌었는지 확인하고 GitHub 프로필의 이미지 표시 너비를 검증한다.
