# GROOVE 프로필 README 보완과 근거

## 요청과 반영 범위

사용자는 학교 6단대 축제 웹사이트를 메인 화면과 함께 공개 프로필 README에 추가하고 바로 push해도 된다고 승인했다. 행사 규모를 조사하고 주막 운영 경험과 연결해 사업·제품 관점을 설명한다. 기존 프로젝트·수상·자격·README 양식은 유지하며 관련 없는 로컬 PDF 삭제·이름 변경은 커밋하지 않는다.

## 작성 방향과 작업 계획

- 기술 기능만 나열하는 방법, 운영 경험만 소개하는 방법 중 하나에 치우치지 않고 현장 운영 → 문제 정의 → 주문·입금 확인 흐름 → 데이터 정합성 구현을 연결한다.
- 기존 Projects 1~9를 재번호화하지 않고 GROOVE를 10번에 추가한다. Current Focus와 명시적 `groove-festival` 바로가기도 추가한다.
- 학부 재학생의 대상 규모, 실제 이용자 수, 현장 운영 인원과 전적 대학 총매출을 분리한다. 근거 없는 비용 절감률·매출 증가율·동시접속 수는 만들지 않는다.
- 실제 공개 홈페이지 캡처와 공식 통계·본인 기여 근거를 확인한 뒤 관련 MD와 이미지 한 장만 커밋·푸시한다.

- 개인 기여: 서버 작성자 커밋 `7f21a2ffcba71a59013bfdf6dc3a72e0f0cadd18` 및 2026-09-20 병합된 본인 작성 PR의 주막 지도·QR 주문 API를 확인했다. private 서버 원본 코드는 복사하지 않는다.

- 공개 홈 화면은 팀 결과물이며 개인 프론트엔드 구현으로 주장하지 않는다.

## 운영 경험의 연결

사용자가 2026-10-05 확인한 컴퓨터학부 주막 39명 운영 총괄과 메뉴·가격·매출관리·영업·동선 개선 경험을 연결했다. 전적 대학의 3일간 1,700만 원은 총매출 참여 경험이며 순이익·개인 수익·이번 경북대 행사 매출로 쓰지 않는다.

입금 확인을 은행 API로 자동화했다고 쓰지 않는다. 손님이 입금자명을 제출하고 관리자가 실제 입금 내역을 확인하는 흐름으로 설명한다. 정량 절감률·현재 행사 매출·서비스 이용자 수는 확보하지 못했으므로 넣지 않는다.

## 이미지

`assets/portfolio/groove-home-20261007.png`는 공개 홈페이지의 실제 메인 화면이다. 내장 브라우저에서 페이지 내용과 디자인을 확인했지만 저장용 캡처가 반복 실패하여, 공개 URL만 전달하는 원격 웹페이지 캡처 API로 원본 PNG를 확보했다. 별도 로그인·비공개 자료·개인정보·계좌정보는 전달하지 않았다.

- 렌더 원본: 1200×1200 PNG, 첫 화면 1200px 영역.
- 축제명·일정·6단대 표기가 있는 완성된 화면을 직접 확인했다. 로딩 화면이나 원본 디자인 자산을 캡처처럼 사용하지 않았다.
- AI 재생성·사진 합성·수치 변경 없이 원본 캡처를 그대로 사용한다. 홈페이지의 PC 좌우 여백도 원래 화면이다.
- 캡처 방식: [Thum.io 공개 URL 캡처 API](https://www.thum.io/documentation/api/url), `noanimate/png/width/1200/crop/1200/maxAge/0`. 유료 전용 옵션·계정 생성·유료 계약은 사용하지 않았다.

## 검증 범위

공식 집계의 열 의미·대학 행·합계 8,937을 확인했다. README 렌더링·이미지 참조·기존 섹션 보존·커밋 범위·비밀값 제외·원격 게시 확인은 실제 수행한 결과만 추가 기록한다. 축제 서비스 코드는 변경하지 않는다.

### 사전 검증 결과

- 통계 원본 Q/R열과 대학 집계 6행을 대조하여 8,937명, 남 4,758명·여 4,179명을 확인했다. 검증용 복제 시트는 합산하지 않았다.
- 공개 메인 화면에서 6단대·행사 일정·바로가기·22개 주막 지도 표시를 확인했다. 입금·주문 생성·로그인·관리자 정보 열람은 하지 않았다.
- 원격 캡처 PNG의 축제명·일정·6단대·브랜드 아트가 실제 페이지와 일치하는지 시각적으로 확인했고, 1200×1200 PNG 형식과 복사 전후 해시도 대조했다.
- GitHub Markdown 렌더 API에서 `user-content-groove-festival` 앵커·메인 이미지 태그·8,937명 대상 표기가 생성됨을 확인했다. 이미지에는 `max-width: 100%`가 적용됐다.
- 추가한 GROOVE 본문·Current Focus 항목·바로가기만 제거하면 변경 전 README와 정확히 같음을 검사했다. 기존 1~9번 프로젝트·수상·자격·양식은 유지됐다.
- 축제 애플리케이션 코드와 기존 로컬 PDF 변경은 이 작업의 커밋 대상에서 제외한다. 서버·프론트엔드 기능 테스트는 문서 변경 범위에 해당하지 않아 재실행하지 않았다.
