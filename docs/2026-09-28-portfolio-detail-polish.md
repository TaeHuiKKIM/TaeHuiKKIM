# 포트폴리오 세부 배치 개선

- 출력 상단의 README·날짜 표기를 없애고 하단 이름·쪽번호만 유지했다.
- 소개에서 Reqover와 TUG GUARD를 독립된 항목으로 나눴다. 기존 상세 페이지도 각각 유지한다.
- TUG GUARD는 실제 DOM 콘텐츠 영역 1600×812px만 새로 캡처해 우측·하단 바깥 여백을 제외했다. 오른쪽 분석 패널 자체는 제품 UI이므로 보존했다.
- RiskTwin SVG의 입력·출력 설명에 명시적 줄바꿈을 적용해 박스 안쪽 여백을 확보했다.
- PDF의 글머리표 두 번째 줄을 본문 시작선에 맞추고, 영문 단어 중간 잘림 방지 및 기술 표 열 너비를 조정했다.
- 사용자 로컬의 `김태희 포트폴리오.pdf`와 기존 PDF 삭제/이름 변경 상태는 건드리지 않는다. 새 출력은 `output/pdf/김태희 포트폴리오-개선.pdf`이다.

## 검수

13쪽 전체 렌더 확인 및 최종 캡처 반영 후 10쪽 재검수 완료. 이미지 원본 1600×812px 확인, RiskTwin의 모든 박스 내 문구를 글꼴 폭으로 검사해 오른쪽 20px 이상 여백을 확인했다. 최신 지표·수상, 프로젝트별 페이지 분리, 이미지 경로 검사를 통과했다.
