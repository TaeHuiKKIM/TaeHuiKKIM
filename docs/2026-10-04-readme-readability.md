# README 이미지·가독성 개선

현재 공개 프로필을 확인하고 최근 사용자 수정(Reqover 소개의 ‘오픈소스 도구’ 표기)을 포함해 작업했다.

- 개미 투자자 키우기의 두 원본 화면을 같은 표시 높이 480px로 맞추고 간격을 넣었다. 이미지 종횡비를 유지한다.
- 게임 설명과 성과를 이미지 위로 옮기고, 본문은 플레이·개발·운영 세 항목으로 줄였다. 지표는 2026-09-28 사용자 제공 기록이며 이번 작업에서 새 수치를 추정하지 않았다.
- Reqover·TUG GUARD의 제목을 짧게 정리하고 역할·기술을 다음 줄로 나눴다. 상세 구현·기여·검증 내용은 펼쳐보기 안에 보존했다.
- Reqover의 대표 이미지를 코드→API 역조회 화면으로 바꾸고 긴 요청별 리포트를 펼쳐보기로 이동했다.
- Medirole·MERCI 보조 화면을 펼쳐보기에서 크게 볼 수 있게 해 기본 화면의 길이를 줄였다.
- 모든 프로젝트와 수상·자격 내용을 유지한다. 사용자 로컬의 PDF 이름 변경·삭제 상태는 이 작업에 포함하지 않는다.

공개 GitHub 렌더링에서 이미지 로딩, 제목·설명 배치, 펼쳐보기와 이동 링크를 확인한다.
